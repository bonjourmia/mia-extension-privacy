Mia Extension – Privacy Policy

Last updated: 2026-10-22

Mia is a Chrome extension that helps real estate agents retrieve property documents and fill forms using information prepared in the Mia portal. Its side panel shows the connected account, a portal link and the session activity log.

Data we collect and use

  • File uploads: You can upload files in the portal so Mia can extract information and the extension can fill forms (e.g. listing or transaction details). We store uploaded files so we can process them for form-filling and adapt to new AI technology. File content is used only for these purposes and to improve the extension’s functionality.
  • Listing context: The portal provides the listing identifier and data needed for each user-started robot operation. Operation context is associated with the connected account and the robot tabs in Chrome session storage.
  • Authentication and preferences: The extension stores portal-issued refresh credentials, account and session identifiers, a browser-instance identifier, and language and appearance preferences in Chrome local storage. Access tokens use Chrome session storage.
  • Centris: The extension can interact with pages on https://zone.centris.ca when you use it there. Page content is used only to support form-filling and related features. The extension sends listing data and required photos or PDFs to the provider when you request form filling. Page content can also be included in a problem report you explicitly start in the portal.
  • User-started property retrievals: When you explicitly start a retrieval, Mia opens a dedicated tab on Hydro-Québec, PG Municipal, Saint-Hyacinthe, a Ville de Montréal property service, Instanet/TransactionDesk or Matrix. The robot uses a tab opened for the operation or explicitly selected by you. It reads and sends to the Mia backend only the requested estimate, tax bill, valuation role, selected PDF, or the page content needed to create that document for the selected listing.
  • Provider request metadata: During a user-started property retrieval, Mia temporarily processes only the request URL, HTTP method, response status or network error, and provider-tab association needed to determine whether a retrieval step completed. Mia does not collect general browsing history or observe unrelated tabs.
  • Technical diagnostics: Mia may send error codes, sanitized error messages, stack traces, extension version, and listing identifiers to the Mia backend solely to monitor reliability and resolve technical issues. A bounded queue of unsent diagnostics may be kept temporarily in Chrome's local storage.
  • Session activity log: The extension records progress, errors and results with account, operation, execution and tab identifiers and timestamps. This log remains available while the panel is closed and through background-worker suspension during the browser session. The extension also notifies portal tabs of robot state changes so they can refresh the operation's data from Mia.
  • User-started problem recordings: When you start a problem recording in the portal, the extension can collect HTML evidence from robot tabs belonging to the connected account and return it to the portal for the report. HTML evidence can include page text, form values and property or contact information displayed on the page. This collection is limited to the recording and the account's robot tabs.

What we do not do

  • We do not sell or rent your data or share it with advertisers or data brokers. Mia uses hosting, storage and document-analysis service providers to process the information required for the requested workflows.
  • We do not use your data for advertising or for purposes unrelated to the extension's functionality (form-filling and improving it with new AI technology).
  • We do not collect general browsing history, block or modify provider network traffic, or monitor tabs unrelated to a user-started Mia robot operation or problem recording.

Storage and security

  • Access to your data is authenticated through a portal-issued session and tied to the connected account and its permissions.
  • Portal-issued refresh credentials, account and session identifiers, the browser-instance identifier, preferences, queued sanitized diagnostics and pending cancellations are kept in Chrome local storage. Pending cancellations can retain their operation context and the credential needed to notify Mia until delivery succeeds. Access tokens, robot state and queues, operation-to-tab associations, temporary problem-recording HTML evidence and the activity log use Chrome session storage and disappear when Chrome exits.
  • Activity-log limits: The log is capped at 5,000 entries and 2 MiB. Older entries are removed when a limit is reached, with an indication in the panel. The log is also cleared on disconnect or account change.
  • Uploaded files are stored on our systems for processing and to adapt to new AI technology. We handle them in line with this policy.
  • Data sent between the extension, provider websites, and the Mia backend is transmitted over HTTPS, except when a developer deliberately uses the local development build with localhost services.

Changes

We may update this policy occasionally. The "Last updated" date at the top will be revised when we do. Continued use of the extension after changes means you accept the updated policy.
