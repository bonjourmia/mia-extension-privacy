Mia Extension – Privacy Policy

Last updated: 2026-09-08

Mia is a Chrome extension that helps real estate agents retrieve property documents and fill forms using file uploads and AI, via a side panel that works with Centris.

Data we collect and use

  • File uploads: You can upload files so the extension can extract information and fill forms (e.g. listing or transaction details). We store uploaded files so we can process them for form-filling and adapt to new AI technology. File content is used only for these purposes and to improve the extension’s functionality.
  • Selected listing ID: When you select a listing in the extension, its ID is stored locally in your browser so the extension can restore your selection. This stays on your device.
  • Authentication and preferences: The extension stores the access key used to authenticate with Mia, a browser-instance identifier, and language and display preferences in Chrome's local storage.
  • Centris: The extension can interact with pages on https://zone.centris.ca when you use it there. Page content is used only to support form-filling and related features in the extension and is not sent to us or to any third party.
  • User-started property retrievals: When you explicitly start a retrieval, Mia opens a dedicated tab on Hydro-Québec, PG Municipal, Saint-Hyacinthe, or a Ville de Montréal property service. It reads and sends to the Mia backend only the requested estimate, tax bill, valuation role, or the page content needed to create that document for the selected listing.
  • Provider request metadata: During a user-started property retrieval, Mia temporarily processes only the request URL, HTTP method, response status or network error, and provider-tab association needed to determine whether a retrieval step completed. Mia does not collect general browsing history or observe unrelated tabs.
  • Technical diagnostics: Mia may send error codes, sanitized error messages, stack traces, extension version, and listing identifiers to the Mia backend solely to monitor reliability and resolve technical issues. A bounded queue of unsent diagnostics may be kept temporarily in Chrome's local storage.

What we do not do

  • We do not sell, rent, or share your data with advertisers, data brokers, or other third parties.
  • We do not use your data for advertising or for purposes unrelated to the extension's functionality (form-filling and improving it with new AI technology).
  • We do not collect general browsing history, block or modify provider network traffic, or monitor tabs unrelated to a retrieval explicitly started in Mia.

Storage and security

  • All data is protected by the shared secret you receive and use to initialize the extension. Access to your data is tied to that secret.
  • The access key, selected listing ID, browser-instance identifier, preferences, and any queued sanitized diagnostics are kept in Chrome's local storage on your device. Temporary provider operation-to-tab associations use Chrome session storage and disappear when Chrome exits.
  • Uploaded files are stored on our systems for processing and to adapt to new AI technology. We handle them in line with this policy.
  • Data sent between the extension, provider websites, and the Mia backend is transmitted over HTTPS, except when a developer deliberately uses the local development build with localhost services.

Changes

We may update this policy occasionally. The "Last updated" date at the top will be revised when we do. Continued use of the extension after changes means you accept the updated policy.
